generate_trading_scenario(scenario_type: &str) -> TradingScenario:
  Struct TradingScenario { id, description, market_data, correct_action, biases_tested, difficulty }
  Scenario types:
  1. "endowment_effect": User given a position that's losing. Correct action often = sell. Bias: holding because you own it.
     Description: "You bought AAPL at $185. It's now $172 (-7%). Recent earnings were mixed. Market sentiment is neutral. What do you do?"
     Market shows declining trend with some volatility.
  2. "loss_aversion": Small loss scenario where cutting loss is optimal.
     Description: "Your SPY short is down 3%. Momentum indicators suggest further downside. But closing means realizing a loss. Decision?"
  3. "anchoring": Previous price info biases current decision.
     Description: "MSFT hit $400 last month, now at $365. Is it 'cheap'? Consider: earnings revised down 8%, sector rotation occurring."
  4. "recency_bias": Recent streak shouldn't predict next move.
     Description: "Your last 5 trades were winners. You see a setup you'd normally skip. Do you take it because you're 'hot'?"
  5. "confirmation_bias": Seeking info that confirms existing view.
     Description: "You're bullish on TSLA. One analyst upgrades, three downgrade. News is mixed. Do you buy more?"
  6. "sunk_cost": Previous investment shouldn't affect future decisions.
     Description: "You've spent 40 hours researching a biotech stock. Data now suggests the thesis is broken. Walk away?"
  Generate at least 10 unique scenarios per bias type (60+ total scenarios).

review_flashcard(pool, card_id, quality: u8) -> Result<Flashcard>:
  quality: 0-5 (0=complete blank, 5=perfect instant recall)
  
  if quality < 3:
    // Reset: start over
    card.repetitions = 0
    card.interval_days = 1
    card.ease_factor = max(1.3, card.ease_factor - 0.2)
  else:
    if card.repetitions == 0: card.interval_days = 1
    else if card.repetitions == 1: card.interval_days = 3
    else: card.interval_days = (card.interval_days as f64 * card.ease_factor).round() as i32
    
    card.ease_factor += 0.1 - (5 - quality) as f64 * (0.08 + (5 - quality) as f64 * 0.02)
    card.ease_factor = max(1.3, card.ease_factor)
    card.repetitions += 1
  
  card.next_review_date = today + card.interval_days
  card.last_reviewed_at = now()
  Update in DB and return
