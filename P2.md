Backend auth_service.rs — Implement fully:

1. register(pool, request) -> Result<AuthResponse>:
   - Validate email format and password (min 8 chars, must have uppercase, lowercase, digit)
   - Check email uniqueness (return Conflict error if exists)
   - Hash password with bcrypt (cost factor 12)
   - Insert user into DB
   - Create initial user_levels row: level 1, status 'active', week 1, day 1
   - Create default user_schedule row
   - Generate access_token (24h expiry) and refresh_token (7 day expiry)
   - Store refresh_token hash in refresh_tokens table
   - Return AuthResponse with user data + tokens

2. login(pool, request) -> Result<AuthResponse>:
   - Find user by email (return Unauthorized if not found)
   - Verify password with bcrypt (return Unauthorized if wrong)
   - Check user status is 'active'
   - Generate new token pair
   - Store refresh token
   - Return AuthResponse

3. refresh(pool, refresh_token_string) -> Result<AuthResponse>:
   - Find non-revoked refresh token by hash
   - Verify not expired
   - Revoke old refresh token
   - Generate new token pair
   - Store new refresh token
   - Return AuthResponse

4. logout(pool, user_id, refresh_token_string) -> Result<()>:
   - Revoke all refresh tokens for user
   - Return success

services/metrics_service.rs:

calculate_brain_score(pool, user_id, date) -> f64:
  Formula: (completion_rate * 0.40) + (avg_accuracy * 0.30) + (avg_focus * 0.20) + ((100.0 - stress_index) * 0.10)
  Where:
  - completion_rate = (completed_exercises / total_planned_exercises) * 100
  - avg_accuracy = average of all accuracy_score values for the day
  - avg_focus = average of all focus_rating values (scaled to 0-100)
  - stress_index = derived from HRV and sleep quality (lower is better)

calculate_stress_index(pool, user_id, date) -> f64:
  If HRV available: (100 - normalized_hrv) * 0.5 + (100 - sleep_quality*10) * 0.3 + self_reported_stress * 0.2
  If no HRV: (100 - sleep_quality*10) * 0.5 + (10 - avg_focus) * 10 * 0.3 + missed_sessions * 20 * 0.2

calculate_longevity_score(pool, user_id) -> f64:
  Based on Lancet Commission risk factors (12 modifiable factors):
  - Physical activity (+15 if exercise_minutes >= 150/week)
  - Sleep quality (+10 if avg sleep quality >= 7)
  - Cognitive engagement (+15 if brain_score >= 70)
  - Social interaction (+5 if community engagement)
  - Diet quality (+10 if diet logged and omega-3 tracked)
  - Meditation/stress management (+10 if meditation streak >= 7)
  - Education/learning (+10 if active learning topics)
  - Depression/mood (+10 if stress_index < 40)
  - Hearing protection (+5 baseline)
  - Alcohol/smoking (-10 if flagged, +5 baseline)
  - Air quality (+3 baseline)
  - Head injury prevention (+2 baseline)
  Score = sum, capped at 100
